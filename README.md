## Improvement of Deep Learning Models to Predict the Knowledge Level of Learners based on the EdNet Data
This code contains the model architecture proposed in the SANTE paper ([link](https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE10673786)).
In this work, we propose a novel deep learning model called Self-Attentive Knowledge Tracking Extended (SANTE) to predict learners’ knowledge levels based on the EdNet dataset, and we introduce various features to enhance the model’s performance.
